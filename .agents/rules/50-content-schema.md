# 콘텐츠 스키마 & 저장·공유 규칙

## frontmatter 표준 (모든 가이드 공통, Velite로 검증)
- `title`(한글 제목), `titleEn`(영문 병기 제목)
- `slug`(URL 조각. 소문자·하이픈. **한 번 정하면 절대 바꾸지 않는다** — QR/공유 링크가 깨짐)
- `category`("assessment" | "care_guide" | "calculator")
- `species`(["dog"], ["cat"], 또는 둘 다)
- `summary`(160자 이내 요약)
- `sources`(근거 출처 배열, 최소 1개 필수)
- `cover`(대표 이미지, 선택)
- `updated`(수정일), `reviewedBy`(검수자), `nextReview`(다음 검토일), `guidelineVersion`
- `draft`(기본 false)

## 점수 저장 (assessment 도구)
- 점수 저장 로직은 반드시 `lib/storage.ts` **한 곳에 추상화**한다. 컴포넌트는 이 인터페이스만 호출한다.
- 1단계(현재): 식별코드("이름 + 간단 숫자") + 브라우저(localStorage) 저장. 결과 화면은 인쇄/캡처 가능하게.
- 2단계(향후): 같은 인터페이스를 Supabase로 교체해 기기 간 기록 공유. 콘텐츠·컴포넌트는 건드리지 않는다.
- ⚠️ 식별코드는 비밀번호가 아니다(보안 기능 아님). 민감 의료정보는 저장하지 않는다. 화면에 "간단 기록용" 안내를 표시한다.

## 인쇄(PDF) 대응
- 모든 페이지에 "인쇄/PDF 저장" 버튼을 둔다.
- print 전용 스타일: 상단 메뉴·CTA 버튼·인터랙티브 토글은 인쇄 시 숨기고, 본문·체크리스트·표만 깔끔히 출력. 체크리스트는 손으로 체크할 네모칸으로 표시.

## QR / 공유
- 각 가이드 페이지에 slug 기반으로 전체 URL을 만들어 **QR 코드를 자동 생성**한다(`qrcode.react` 등).
- QR은 화면과 인쇄물 양쪽에 표시(진료실에서 보호자가 폰으로 스캔 → 집에서 다시 보기).
- slug가 안정적이어야 QR/공유 링크가 깨지지 않는다(위 slug 불변 규칙 참조).
