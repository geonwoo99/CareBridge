# 프로젝트 개요 — 보호자 교육자료 사이트

## 정체성
- 이 프로젝트는 수의사가 보호자(반려동물 주인)에게 제공하는 **건강 교육자료 웹사이트**다.
- 운영자 브랜드명·연락처 등은 절대 코드에 직접 쓰지 말고, 반드시 `lib/site.config.ts` 한 곳에서만 가져온다. (현재 브랜드명: "DVM. Geonwoo Ko". 추후 병원 소속이 바뀌면 이 파일만 수정한다.)
- 콘텐츠는 앞으로 수십~수백 개로 확장된다. **모든 결정은 "100개가 쌓여도 흔들리지 않는가"를 기준으로 내린다.**

## 절대 원칙 (가장 중요)
1. **콘텐츠와 디자인을 절대 섞지 않는다.** 글(MDX) 안에 색상·크기·여백 같은 디자인 값을 직접 박아넣는 것을 금지한다. 디자인은 항상 디자인 토큰과 컴포넌트로만 표현한다.
2. **콘텐츠(글)와 도구(로직)를 분리한다.** 새 페이지를 만들 때 가장 먼저 "이건 글인가, 계산/평가 도구인가"를 판단한다. (자세한 규칙은 `10-content-vs-code.md` 참조)
3. **단일 출처 원칙.** 브랜드 정보, 면책 문구, 디자인 값은 각각 정해진 한 곳에서만 정의하고 모든 페이지가 그것을 참조한다.
4. **의학 정보는 임의로 생성하지 않는다.** (자세한 규칙은 `40-medical-safety.md` 참조)

## 기술 스택 (확정)
- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Velite (콘텐츠를 Zod 스키마로 검증·타입생성하는 콘텐츠 레이어)
- MDX (글 + 인터랙티브 컴포넌트)
- 배포: Vercel
- 향후 추가 예정(지금은 만들지 않음): Supabase(식별코드 기반 점수 저장), Keystatic(비개발자용 편집기)

## 사용자 특성
- 운영자는 개발 경험이 거의 없고, 대부분의 작업을 AI 에이전트에게 맡긴다.
- 따라서 코드를 만들 때는 **왜 그렇게 했는지 한국어 주석을 충분히 달고**, 운영자가 직접 만질 가능성이 높은 파일(콘텐츠, 설정)은 특히 친절하게 설명한다.
